# বাজার দর

## Description

বাজার দর is a Bengali-language market price information app that helps people check everyday product prices, compare price changes, and browse products by category. It also includes account sign-in and profile management.

## Technologies Used

- **Next.js 16** with the App Router
- **React 19** and **TypeScript**
- **Tailwind CSS 4**, DaisyUI, and HeroUI
- **Better Auth** for authentication
- **MongoDB** for database integration
- **React Toastify** for notifications

## Features

- Browse a catalog of everyday products and their market prices.
- See products whose prices have increased or decreased.
- Browse products by category.
- Sort products on category pages.
- Open product detail pages.
- Create an account or sign in with email and password.
- Sign in with Google or GitHub.
- View and update the account profile name.
- Responsive Bengali-language interface with loading and not-found pages.

## Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run start` — serve the production build
- `npm run lint` — run ESLint
